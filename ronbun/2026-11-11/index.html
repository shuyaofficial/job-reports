Guiding Data Allocation for Robust Subpopulation Generalization

学習データのサブグループ比率を完全に均等にすることが、ロバストな汎化の唯一の最適解ではないことを理論的に示した。多くの不均衡な構成でも均衡データと同程度の性能が得られ、勾配に基づいて比率を調整する方が、単純なバランシングより効率的に精度と最悪グループ精度を改善できるとしている。

  • 背景: 機械学習モデルは学習データ上の平均精度が高くても、サブポピュレーションシフトによりテストデータで性能が落ちることがある。従来はサブグループ比率を均等にするデータ中心の対策が一般的だが、完全なバランシングはコストが高く、実現できない場合や必ずしも必要ではない場合がある。
  • 手法: Gaussian feature modelの枠組みを拡張し、一般的な学習サブグループ分布に対する性能の全体像を理論的に特徴づけた。さらに、調整後精度と最悪グループ精度を効率的に向上させるためのサブグループ比率の勾配方向を導出した。
  • 結果: 大きく不均衡な構成を含む複数の構成が、均衡データと同程度の性能を示すことを示した。
  • 示唆: データの配分を戦略的に設計することは、単純なバランシングよりも柔軟で原理的なロバスト性向上の道筋になりうる。

Multi-Agent Screening: What Agreement and Acceptance Cannot Tell You

Benjamin Chang、Dell Zhang・arXiv

AIエージェントがスクリーニングした結果について、一致や人間による採択だけでは誤りを判定できない。再現率を特定できるのは、エージェントが通過させなかった項目を無作為抽出で評価した場合に限られる。

  • 背景: エージェント型検索、eディスカバリー、AIによる論文査読などでは、AIエージェントが項目を選別し、高コストな人間の評価者が判定するのは通過した項目のみである。
  • 手法: 「エージェント同士の一致」「評価者による採択」「どのエージェントがどの関連項目を見つけたか」という3種類の証拠が、誤りについて何を示せるかを理論的に分析した。
  • 結果: 一致は正しさを保証せず、採択は適合率を示すものの再現率の下限しか示さない。発見の相関が負でなければ再現率の上限が得られる。真の再現率は、通過しなかった項目を無作為に抽出して判定することでしか推定できず、そのサンプルサイズはエージェント数に依存しない。
  • 示唆: エージェントの性能を信頼する前に、除外された項目の一部を人間が確認する設計が必要である。

  • 背景: エージェント型強化学習と多教師オンポリシー蒸留（MOPD）は補完的な後処理手法だが、視覚エージェントではツール利用に2つの課題がある。モデルがツールの返す有用な観測を見落とすことと、根拠の弱い行動が後続の蒸留に使える証拠を減らすことである。
  • 手法: Ground-Drop-GRPO（GD-GRPO）は証拠を意識した報酬と元の画像入力の確率的な除去を用い、空間・時間の専門家モデルを学習させる。Observation-Gated-MOPD（OG-MOPD）は展開の途中で不十分なツール行動を正規の行動に置き換え、修復された観測から蒸留を再開する。
  • 結果: 14の画像・動画ベンチマークでMix-RLとvanilla MOPDを上回った。アブレーションでは、結果ベースのGRPOと比べてGD-GRPOが観測への依存度とツールによる利得を高めた。
  • 示唆: 出力分布だけでなく観測状態を整合の対象とすることが、視覚エージェントの後処理に有効である可能性を示している。

WorkflowArena: Benchmarking Executable Workflow Orchestration in LLM-Based Multi-Agent Systems

  • 背景: LLMエージェントは単体ではなく複数エージェントで動くようになり、どう分業させるかをモデル自身が実行時に決めるようになった。しかし既存ベンチマークは最終タスク達成率か、事前定義された構造での協調しか測っていない。
  • 手法: ソフトウェア工学や形式数学、法律分析、3D制作など8分野・145の長期タスクからなる WorkflowArena を提案。成果物は相互依存する複数の構成要素からなり、非公開の検証器で評価する。委譲の記録も残し、成果物の質と作業組織を同時に評価する。
  • 結果: 9モデルで比較したところ、全分野で最良の構成はなかった。高い effort 設定では、Claude Code の Claude モデルはワークフロー起動が少なく大きなワーカー群を使い、Codex の GPT モデルは小さな単位で頻繁に委譲した。実行モデルを固定した難しいサブセットでは、Claude Opus 5.5 が作ったワークフローが弱い実行モデルの性能を大きく改善した。
  • 示唆: ワークフローの組織化そのものが、タスク性能を左右する測定可能な要因だと示された。

World In-Context Learning for Agentic Robot Manipulation

Heng Fang、Zehui Guo、Yuehan Zhang ほか・arXiv

固定されたLLMをシミュレータ上でのリハーサルによって学習させ、その経験をモデルの重みではなくコンテキストに書き込む「World In-Context Learning (WICL)」を提案した。1件のデモから重みの更新なしで、RoboTwin 2.0の50タスクで平均83.4%の成功率を達成し、学習済み方策を20ポイント以上上回った。

  • 背景: 学習済み方策は技能を重みに埋め込むため、学習時の分布に結び付いてしまう。文脈内学習（ICL）はこの制約を回避できるが、別シーンのデモには現在の世界からのフィードバックがなく、学習済み方策に届いていなかった。
  • 手法: 固定モデルがデモから出発し、シミュレータなどの世界でタスクをリハーサルし、フィードバックを重みではなくコンテキストに書き込む。これを実装したモジュール式基盤「RoboScript」では、学習結果を Task Memory として凍結し、新しいシーンに展開する。
  • 結果: RoboTwin 2.0の全50タスクで、1デモ・勾配更新なしで平均83.4%の成功率（clean/randomized両設定）。最強の学習済み方策を20ポイント以上上回った。さらに、視覚分布をまたいだ汎化、リフレクションによる改善、基盤モデルの規模に応じたスケーリングを示し、クロスエンボディメント記憶の適応により物理的な双腕ロボットへの転移も確認された。
  • 示唆: 世界をループに組み込めば、ロボットは操作タスクを重みではなくコンテキストで学習しても、重み学習と同程度に習得できる可能性がある。コードは https://github.com/ArcheOne-AI/RoboScript で公開されている。
