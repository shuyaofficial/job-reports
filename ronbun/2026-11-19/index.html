組織間AIエージェントの信頼基盤

身元確認と認可を外部層で行い攻撃封じ込め率を43%から84%に

84%攻撃封じ込め率（改善後）

困りごと組織をまたぐエージェントの身元・実行整合性が未検証
やったこと証明書と承認済みモデル・ツールを入口で検証
結果攻撃封じ込め率43%→84%、遅延は約174μs
くわしく読む

AI エージェントが組織をまたいで協調する際に必要な、身元確認・実行整合性・認可の仕組みを提供する「Agent Trust Infrastructure (ATI)」を提案しています。ATI をフレームワーク非依存の外部防御層として実装し、攻撃の封じ込め率を 43% から 84% に高めつつ、リクエストあたりのオーバーヘッドは約 174 μs に抑えました。

背景
エージェントが他組織のエージェントやツールとやり取りする場面が増えていますが、CrewAI や LangGraph などの既存フレームワークには、組織間でエージェントの身元や実行構成を検証する共通の仕組みがありません。
手法
PKI、ゼロトラスト、リモートアテステーションを組み合わせ、組織ごとの認証局（AgentCA）同士のピア関係で信頼を連携させます。リクエスト前に証明書、承認済みのモデル・ツール・システムプロンプトを検証し、3 つのポリシーチェックで認可します。IETF WIMSE と Entity Attestation Token の形式を用いたオープンソース実装です。
結果
8 組織・6 フレームワーク・5 モデルを用いた評価で、攻撃封じ込め率は 43% から 84% に向上しました（全構成で一貫評価した 11 シナリオでは 40% から 80%）。モデル差し替えとシステムプロンプト改変の攻撃はすべて防げました。一方で、データ内に埋め込まれたプロンプトインジェクションは対象外です。
示唆
エージェントを独立したセキュリティ主体として扱い、モデルの振る舞いに依存しない決定的な検証を入口で行うことの有効性を示しています。ただし、評価は模擬環境と限定的な攻撃セットによるもので、実運用での効果は今後の検証が必要です。

Agent Trust Infrastructure (ATI): A Federated Identity, Trust, Attestation, and Accountability Architecture for Cross-Organization Autonomous AI Agents
Viet K. Nguyen、Mohammad I. Husain・arXiv

少データ学習の高温度正則化

凍結モデルを高温度で模倣させ少データでも性能向上

26.7%最良基準比のperplexity低下

困りごと少データで過学習と分布の裾の忘却が起きる
やったこと高温度の出力分布を教師に合わせる正則化を追加
結果ドメイン適応でperplexity最大26.7%低下
くわしく読む

事後学習（SFT）のデータが少ないと過学習やデータ分布の裾の忘却が起きる問題に対し、凍結した事前学習モデルを高温度で模倣させる正則化項「Ambient SFT」を提案し、標準SFTより高い性能を示した。温度パラメータで事前学習モデルへの信頼度を調整でき、T→∞で通常のSFT、T=1で知識蒸留に一致する。

背景
事後学習データは事前学習データより桁違いに少なく、SFTでは過学習やデータ分布の裾（tail）の忘却が起きやすい。
手法
事前学習モデルを凍結した教師とし、学習モデルの高温度（T）での条件付き分布を教師の高温度分布に合わせるKLダイバージェンス項（Temperature Matching）を、通常のSFT損失に加える。
結果
ドメイン適応では最良のベースラインより最大26.7%低いperplexity、指示チューニングでは平均相対改善8.0〜20.3%、推論ベンチマークでは6つ中5つで勝利。アブストラクトでは標準SFTに対し平均相対改善が最大21%とされている。
示唆
大規模なデータ収集を伴わずに、事前学習モデルを「ノイズのある教師」として活用することでデータ効率を高められる可能性がある。

Ambient LLMs: Data-Efficient Supervised Fine-tuning via Temperature Matching
Giannis Daras、Marios Papachristou、Adam Klivans ほか・arXiv

ほぼ実行可能を保つ確率的分散低減法で計算量を大幅改善

制約付き凸有限和最適化問題に対し、反復点がほぼ実行可能性を保つ不完全SVRG法を提案する。ε-SFSO解の一階オラクル計算量を従来法より大幅に改善し、単一関数の場合は錐最適化向けの新しい決定的一階法になる。

背景
制約の多くが必須要件（ハード制約）である実問題では、近似解がほぼ制約を満たす必要がある。既存のSVRFP法はε-SFSO解の計算量が悪く、ε-EFSO解との間に大きな差があった。
手法
制約付き近似点問題（射影付きの近接作用素）を、一階近接拡張ラグランジュ法で得られるε-KKT解によって不完全に解く不完全SVRG法を提案。反復点がほぼ実行可能に保たれる「実行可能側」の手法である。
結果
ε-SFSO解を O(s log s + s^{1/2}ε^{-1/2}) 回の∇f_i評価（ほぼ同等のε^{-1/2}オーダー）で計算でき、従来の O(s log s + s^{1/2}ε^{-3/2}) を大きく改善。s=1の場合は∇f_1評価が O(ε^{-1/2}) の決定的一階法となる。
示唆
制約勾配や錐への射影が目的関数の勾配より安価な場合に、従来法より実用的な性能が期待できる。

An inexact stochastic variance-reduced gradient method for constrained convex finite-sum optimization

小規模言語モデル（SLM）が出す予測の不確実性をリスク信号として使い、リスクが高いサンプルだけを大規模言語モデル（LLM）へ回す閾値ゲート型のハイブリッド推論を提案している。追加のルーター学習なしで、GLUE-X の OOD 汎化設定において精度・頑健性を改善しつつ LLM 呼び出し比率とコストを抑えられることを示している。

背景
LLM は汎化性能が高いが推論コストが大きく、教師ありの分類タスクでは現地展開した微調整済み SLM に必ずしも勝らない。一方で SLM は OOD・ドメイン変化に弱い。既存のハイブリッド推論は学習済みルーターに依存し、生成タスク向けが中心で、ID→OOD 転移の教師あり分類では安定的かつ解釈可能な協調が十分に検討されていなかった。
手法
LinkModel は「Prediction–Estimation–Prediction」の仕組みを採る。ローカルで微調整した SLM がまず予測し、同時に不確実性を推定してリスク信号を得る。閾値ゲートのポリシーがリスクの高いサンプルを LLM に渡し、LLM が二段目の予測を行う。ルーターの追加学習は不要。
結果
GLUE-X の OOD 汎化設定で体系的に評価し、複数の学習–テスト転移の組み合わせで一貫したエンドツーエンドの改善を確認した。OOD での性能低下を大きく緩和し、LLM 呼び出し比率とコストも制御できたと報告している。
示唆
不確実性推定に基づく単純な閾値ゲートでも、SLM と LLM を低コストかつ解釈可能に組み合わせられ、ドメインシフト下の実運用に有効な選択肢になりうる。

LinkModel: uncertainty-guided hybrid inference between small and large language models for out-of-distribution generalization
Wentao Bai、Jiale Song、Fan Guo ほか・Complex & Intelligent Systems

背景
直近N フレームの sliding window で動画に答えるVLMは、ハイブリッドモデル（GDN等の線形再帰層を含む）では、古いフレームを状態から除くのに窓全体を再計算する必要があり高コスト。
手法
再帰更新が状態に関してアフィン（S_t = S_{t-1}A_t + B_t）である点に着目し、各フレームの (A, B) 係数をキャッシュ。セグメント木で結合し O(log W) 回の合成で状態を再構築。アテンションのKVは穴埋め（スロット再利用）とRoPEの再基準化で管理。学習不要。
結果
5〜6種のオープンソース・ハイブリッドVLM、4つの動画推論ベンチマークで、オンライン評価のp95 TTFTが全20組合せで最小。vLLM系ベースラインより幾何平均6.6倍（最大35.7倍）低減、精度は平均+2.3pt。
示唆
除去は層内では厳密だが、期限切れフレームは前段層が計算した入力を通じて残留影響を持つ（KV eviction と同様の近似）。メモリ増加は9Bモデルで4.8GiB（約18%）。
